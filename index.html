Fresh Mac

Returning
1 Xcode Command Line Tools
This installs Git and other essentials. A system popup will appear — click Install and wait 2-5 minutes. If it says "already installed", move on.
xcode-select --installCopy
2 Homebrew
macOS package manager. Makes installing everything else clean. Takes 1-2 minutes.
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"Copy
Important: After install, it prints 2 lines to run. They look like this — copy and run them:
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"Copy
3 Node.js
brew install nodeCopy
Verify: node -v should show v22 or higher.
4 Launch the setup wizard
git clone https://github.com/catMarvin/start-wikitata.git ~/start-wikitata && cd ~/start-wikitata && npm install && node server.jsCopy
Browser opens automatically to localhost:3737 with the full setup wizard. It handles everything else — SSH keys, CLI tools, Claude Code config, shell setup.
