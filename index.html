wikiTaTa

Developer setup for your Mac.
One command. Everything configured.

Paste this in Terminal
git clone https://github.com/catMarvin/start-wikitata.git ~/start-wikitata && cd ~/start-wikitata && npm install && node server.js

What happens next

1
Browser opens automatically with the setup wizard at localhost:3737
2
Choose your level — full setup, dev tools only, or just Claude Code config
3
Enter your invite code — Todd gave you a username and code
4
Run each step — test, install, or skip. Built-in terminal runs commands for you
5
Type claude — Claude Code knows who you are. Say start session sop

Already cloned? Just run: cd ~/start-wikitata && node server.js

Need Node.js first? Visit nodejs.org or run: curl -fsSL https://fnm.vercel.app/install | bash

Requires macOS + Node.js 18+
